# 审计与验证记录 · 2026-10-02

## 范围与方法

本轮围绕路由与鉴权、短链创建/管理/跳转、访问口令、缓存、统计回刷与查询、存储迁移、前端状态与公共组件、Docker/CI/反向代理进行了源码检查及回归验证。历史工作笔记仅用于定位线索；不将旧验收记录当作本轮证据。第三方依赖实现、生产服务器实际配置、线上流量和数据库内容不属于本地审计证据。

保留原 Vue + Go 架构和 REST 路径，新增两项数据库迁移。用户原有 `.gitignore` 修改未覆盖。

## 上线注意与保留限制

- 本轮未操作线上服务器。生产需按 [部署说明](DEPLOY-1PANEL.md) 填写实际 OpenResty 对端地址、挂载信任配置并验证防火墙。默认配置不信任任何代理头。
- 新旧 worker 不可并行运行；升级和回滚前必须维护并排空计数，保留成对备份。回滚可保留新增 schema。
- 幂等针对同一已持久化批次。仍保留队列满丢弃、Redis 不可用时统计降级；不承诺纠正历史计数，也不承诺 Redis 数据丢失后精确恢复。
- 数据库批次去重表和 Redis 代际标记暂不自动清理，需监控存储增长。
- 缓存更新仍采用数据库更新后主动失效；Redis 失效失败或跨实例并发回填存在 TTL 窗口。涉及紧急撤销时，应结合维护入口和缓存清理，不将本轮版本字段视为跨存储强一致协议。
- 自定义域名仍由受信任运维登记；不新增域名管理、DNS 验证、邮件验证、账号找回或暗色主题。
- 本轮为本地代码与功能审计，不等同于独立渗透测试、依赖供应链审计或生产容量压测。
